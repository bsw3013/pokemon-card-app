## 1단계. 데이터 기초 정리 — 결과와 관리 방법

### 저장 형식
| 저장 위치 | 내용 |
|---|---|
| `settings/catalog` (새로 만듦) | **세트 표** `코드 · 이름 · 시대 · 종류 · 한국 발매일 · 총 장수` 65개 + **레어도 표** `코드 · 순서 · 그룹` 21개 |
| `pokemon_cards` | 기존 칸 그대로 + `setCode`(세트 코드), `cardNo`(정렬용 번호), `createdAt`/`updatedAt`(추가·수정 시각) 자동 기록. 예전 보유 정보 칸(status/price/possessions/language/isLegacy)은 삭제 |
| `cardOwnership` | 그대로 (예전 보유 정보 중 아직 없던 것만 옮겨 옴, `migratedFromLegacy: true` 표시) |
| 시세 기록 (`marketListings`, `marketPriceHistory`, `marketWatchlist`) | `cardKey` 가 `id:<카드ID>` 로 바뀜 (예전 키는 `legacyCardKey` 에 보관). 도감에 없는 카드를 직접 입력한 기록은 예전 방식 그대로 |

- 세트 발매일: 포켓몬 카드 공식 사이트(pokemoncard.co.kr)의 한국 발매일
- 총 장수: 카드에 인쇄된 숫자. 실제 카드번호(SR/SAR이 총 장수+1부터 시작)로 검증함. 확인 못 한 7개 세트는 빈칸
- 시대: 메가 / 스칼렛&바이올렛 / 소드&실드 / 썬&문 / XY / 블랙&화이트(샤이니 컬렉션) / 기타(프로모)
- 레어도 그룹: 일반(C·U·R·RR·RRR) / 힛카드(S·A·MA·AR·CHR·CSR·SR·SSR·SAR·HR·UR·BWR·MUR) / 기타(PROMO·기타 AR·없음)

### 처음 한 번만 할 일 (머지 후, 관리자)
1. 마스터 설정 → **세트·레어도** 탭 → **세트·레어도 표 만들기**
2. 마스터 설정 → **데이터 점검** 탭 → **정리할 내용 확인** → 숫자 확인 → **이대로 실행**

### 지금 화면 구성 (3~5단계 결과)
| 메뉴 | 주소 | 내용 |
|---|---|---|
| 홈 | `#/home` | 내 컬렉션 요약, 완성에 가까운 세트, 최근 추가(또는 최신 세트) 카드, 관심 카드, 포켓몬 도감판. 로그인 전에는 검색·최신 세트 |
| 카드 | `#/cards` | 예전 도감 갤러리 + 필터 탐색기. 왼쪽 필터(보유 상태·세트·레어도·종류·언어), 정렬, 카드/표 보기 |
| 세트 | `#/sets`, `#/sets/sv2a` | 시대별 세트 목록과 완성률, 세트 페이지(레어도 구간별 카드) |
| 내 컬렉션 | `#/collection` | 보유 종류·장수·평가액·손익, 보유 카드/세트 완성률/레어도별/관심 카드 탭 |
| 시세 | `#/market` | 기존 시세 화면 |
| 프로필 메뉴 | | 앨범 꾸미기(`#/album`), 마스터 설정(`#/admin`), 닉네임, 로그아웃 |

- 카드를 누르면 어느 화면에서든 같은 상세 창(`?cardId=`)이 열린다. 보기 화면 → [수정]/[보유 정보 기록]
- 보유 기록은 "한 장(같은 조건 묶음) = 한 줄": 수량, 등급(업체·점수·인증 번호) 또는 상태, 언어, 구매가, 구매일, 보관 위치, 판매·교환 가능, 메모
- 마스터 설정 탭: 카드 관리(검색·바로 수정·여러 장 한꺼번에) / 세트·레어도 / 목록값·표시 항목 / 데이터 점검 / 백업·가져오기

### 새 세트가 나왔을 때
1. 세트·레어도 탭 맨 아래 줄에 세트 추가 (코드·이름·시대·종류·발매일·총 장수) → **변경 내용 저장**
2. 카드 CSV 업로드 (series 칸에 `코드 -「이름」` 형식, 세트 코드·번호·추가 시각은 자동)
3. 데이터 점검 탭에서 빈칸 확인
4. `npm run thumbs` 로 썸네일 만들기 → 커밋
5. 백업은 다음 날 새벽 자동

## 2. 참고한 사이트

- **TCGdex / Pokémon TCG API** (카드 데이터 표준): 세트 = 코드·이름·시대·발매일·표기 장수·실제 장수·로고

## 3. 개선안

### A. 데이터 관리
- **세트 목록 따로 만들기**: `코드 | 이름 | 시대(메가/SV/소드실드/썬문) | 발매일 | 총 장수 | 로고`. 카드에는 세트 코드(`sv2a`)만 저장
- **레어도 표**: `이름 | 순서 | 그룹(일반/힛카드/프로모) | 배지 색`
- **데이터 한 번만 불러오기**: 앱을 켤 때 한 번 읽고 모든 페이지가 함께 사용
- **보유 기록 "한 장 = 한 줄"**: `상태 | 언어 | 등급(PSA 10 등) | 구매가 | 구매일 | 보관 위치 | 판매·교환 가능`
  - 같은 조건이면 묶어서 "×3"으로 표시
  - "보유중/등급카드"는 보유 기록을 보고 자동 계산
- **기존 데이터 정리**: 빈칸 채우기, 시리즈 이름 통일, 옛 보유 정보 삭제를 관리자 버튼으로

### B. 메뉴 구성
- 상단 메뉴 하나로 통일: `홈 · 카드 · 세트 · 내 컬렉션 · 시세` + 검색창 + 프로필(앨범, 설정)
- 모바일은 하단 탭바
- '도감 갤러리' + '필터 탐색기' → **"카드"** 하나(왼쪽에 필터). 통계는 내 컬렉션 안으로
- 공유 가능한 주소: `#/card/카드ID`, `#/set/sv2a`

### C. 카드 배치
- **카드 목록**: 이미지 중심. 아래는 `이름 + SV2a 184/165 + 레어도 배지` 한 줄. 데스크톱 7~8장, 모바일 3장. 미보유 흑백 유지, 여러 장이면 "×2" 배지
- **세트 페이지(신규)**: 로고·발매일·완성률 막대 → 번호순 카드, SR/SAR/UR 구간 구분선, `전체 / 보유 / 미보유` 전환
- **카드 상세**: 보는 화면 먼저(큰 이미지, 정보, 시세 그래프, 같은 포켓몬 다른 버전, 내 보유 목록). 편집은 '수정' 버튼으로

### D. 홈페이지
- 로그인 전: 검색창, 최신 세트, 짧은 소개
- 로그인 후: 컬렉션 요약(종류 수·총 장수·평가액), 완성 직전 세트, 최근 추가 카드, 관심 카드 시세 변동, 포켓몬 도감판(유지)

### E. 마스터 설정
- 탭으로 나누기: `카드 관리 | 세트 관리 | 목록값(레어도·종류·등급업체) | 데이터 점검 | 백업·가져오기`
- 데이터 점검: "이름 없음 18장, 종류 없음 801장, 이미지 깨짐 15장, 썸네일 없음 N장" → 누르면 해당 카드로 이동
- 카드 관리: 검색·페이지 나눔·여러 장 한꺼번에 수정되는 표
- 저장은 항목별, 위험한 작업은 "N장이 바뀝니다" 확인창

### F. 디자인 — "AI 티" 빼기
**지금 AI 티가 나는 부분**
- 제목마다 이모지(📊⚙️💎📦🔥), 그라데이션 로고, "PokéDex AI"라는 이름
- 모든 버튼이 알약 모양 + 그림자, 숫자마다 빨강/초록/노랑/파랑
- 둥근 모서리 10종류, 그림자 83곳, 상자 안에 상자
- 영어 폰트(Outfit)에 한글이 없어 한글은 다른 폰트로 섞여 나옴
- 과한 문구: "마스터 시스템 동기화 중", "글로벌 데이터 클라우드 관리", "카드 단일 넘버"

**바꿀 방향**
- 폰트: 프리텐다드(Pretendard) 하나로 한글·영문·숫자 통일
- 색: 차분한 회색 바탕 + 포인트 색 하나(버튼·선택 표시). 상태는 작은 점으로만
- 모양: 모서리 2종류(6px, 10px), 그림자 대신 얇은 선
- 아이콘: 이모지 대신 얇은 선 아이콘 한 세트
- 원칙: 카드 이미지가 주인공, 화면 장식은 조용하게
- 문구: "불러오는 중", "백업", "이름", "카드 번호"처럼 짧게
